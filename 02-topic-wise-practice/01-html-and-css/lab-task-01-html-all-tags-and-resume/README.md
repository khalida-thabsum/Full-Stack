## Lab Task 1 - HTML Elements and Resume

**index.html** walks through HTML one group at a time, with a contents list that jumps to each section: headings, formatting (including `dfn` and `bdo`), character entities, lists (`reversed`, `type`), links (`tel:`, `download`, image links), a table with `colgroup`, form inputs (month, week, time, search, `optgroup`, disabled / readonly) and the semantic containers.

**resume.html** is a two-column resume built with tables only.

Open `src/index.html`.
