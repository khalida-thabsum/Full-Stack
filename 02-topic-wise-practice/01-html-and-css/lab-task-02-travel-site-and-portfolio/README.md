## Lab Task 2 - Travel Site and Portfolio

**Rayalaseema Road Trip** (`src/travel-site`): a five-day route through Orvakal, Belum Caves, Lepakshi, Penukonda and Tirumala. Uses CSS variables, a horizontally scrolling Flexbox route strip, a CSS Grid of stops where the first card spans two columns, a tips grid, and a booking form split into fieldsets.

**Portfolio** (`src/portfolio`): one-page portfolio with pill navigation and two-column Grid sections that collapse to one column on small screens.

Open each `index.html`; resize the window to check the mobile layouts.
