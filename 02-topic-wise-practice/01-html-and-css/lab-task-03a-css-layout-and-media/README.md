## Lab Task 3a - Layout, Positioning and Media

1. Holy grail layout using nested Flexbox
2. Wrapping gallery with `flex: 1 1 150px`
3. Tooltip (absolute inside relative), corner labels and centring with `transform`
4. Full-screen overlay using `position: fixed` and the `:target` selector, with no JavaScript
5. Responsive 16:9 YouTube iframe, `<audio>`, and `<video>` with a captions `<track>`

The side menu uses `position: sticky`. Put `track.mp3` and `demo.mp4` in `src/media/` to try the local players.
