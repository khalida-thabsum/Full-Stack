## React

**react-components-props** - Recipe book: separate props, a boolean-driven badge, a component with a default prop (`SpiceMeter`), a reusable `Modal` that uses `children`, and a controlled `Toggle`.

**state-management-hooks** - Notes app: `useReducer` for add / edit / pin / delete, a custom `useLocalStorage` hook, `useEffect` with cleanup for a Ctrl + K shortcut, `useMemo` for search and sort, `useRef` for focus, and `useId`.

In either folder: `npm install`, then `npm run dev`.
